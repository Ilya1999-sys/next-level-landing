# Next Level — landing

Case page for the Next Level football archive. English copy. Visual language follows the product’s **Nostalgia** mode.

## Tokens

Edit `tokens/` to restyle the page:

- `colors.css` — Nostalgia palette (`#d6d6d6` field, `#012fff` accent, `#e1fb5c` mark)
- `type.css` — display + UI scale
- `space.css` — spacing, radius, glass blur
- `semantic.css` — aliases used by components

Copy lives in `lib/content.ts`. Layout blocks live in `components/sections/landing.tsx`. Media frames are labeled slots for later screenshots.

## Run

```
npm install
npm run dev
```
